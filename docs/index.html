Cluster Interpretation, Visualizations & Strategic Inferences

Validated & Formatted from Distributed Big Data PySpark Outputs

1

Price ≠ Satisfaction

Cluster 0 (Budget/F2P) achieves the highest user satisfaction (95.63%), outranking full-priced AAA blockbusters (89.69%). Lower barrier to entry creates higher player goodwill.

2

Playtime Separates Giants

While Cluster 0 and Cluster 3 both achieve viral status, Cluster 3 generates over 6× higher average playtime (224.2 hrs vs. 36.9 hrs), powered by modding (Skyrim) and deep sandbox loops (Factorio).

3

The "Review Penalty"

Cluster 2 isolates titles suffering from aggressive monetization or botched technical ports (e.g. NBA 2K21, Deus Ex: The Fall), resulting in sub-38% user sentiment regardless of franchise pedigree.

Project Nuances & Limitations

1. Review Count as Popularity Proxy: Total review counts measure community vocalness and historical footprint rather than live concurrent player count.
2. Review Sentiment Bias: Players with polarized emotional responses (ecstatic or deeply frustrated) leave reviews at higher rates than average users.
3. Price Dynamics & Historic Discounts: Dataset reflects snapshot listing prices, without fully weighting historical 80% seasonal Steam sales or humble bundles.
4. Game Age Accumulation: Legacy titles (e.g. Skyrim released in 2011) had over a decade to accrue reviews compared to newer releases.

PySpark ML Transformation Code 

# Feature Skewness Correction & Vector Assembly
df_transformed = df_clean.withColumn("log_price", F.log1p(F.col("price"))) \
    .withColumn("log_popularity", F.log1p(F.col("popularity"))) \
    .withColumn("log_playtime", F.log1p(F.col("playtime_hours")))

assembler = VectorAssembler(
    inputCols=["log_price", "rating_percent", "log_popularity", "log_playtime"],
    outputCol="features_unscaled"
)
scaler = StandardScaler(inputCol="features_unscaled", outputCol="features", withMean=True, withStd=True)

# Train K-Means with K=4
kmeans = KMeans(featuresCol="features", predictionCol="cluster_id", k=4, seed=42)
pipeline = Pipeline(stages=[assembler, scaler, kmeans])
model = pipeline.fit(df_transformed)
